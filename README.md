# SmileCare: Цифровая экосистема стоматологической клиники

**SmileCare** — это специализированное Android-решение, разработанное для нужд стоматологических клиник. Приложение закрывает полный цикл обслуживания пациента: от первичного заполнения медицинской карты до автоматизированного расчёта стоимости лечения и контроля занятости врачебных кабинетов.

---

## 🎥 Видеообзор

Полный сценарий работы системы (создание карты пациента, запись на приём, добавление услуг и проверка конфликтов расписания) продемонстрирован в видеофайле, прикреплённом к релизу или расположенном в директории `demo`.

---

## 🏥 Основные модули системы

Приложение разделено на логические блоки, обеспечивающие работу клиники:

- **Регистратура и расписание:** Управление приёмами. Система не позволит записать двух пациентов к одному врачу на одно и то же время.
- **Кадровый учёт:** База врачей с указанием их специализации, квалификационной категории и стажа работы.
- **Прайс-лист:** Каталог стоматологических услуг с чётким разделением по типам (терапия, хирургия, ортодонтия и др.).
- **Электронная картотека:** Хранение анамнеза жизни пациента, информации о хронических заболеваниях и аллергических реакциях (критически важная функция для стоматологии).

## ⚙️ Техническая реализация и защита данных

В основе приложения лежит локальная база данных **SQLite (Room)**, работающая в связке с **Jetpack Compose**. Главный упор сделан на надёжность и предотвращение ошибок персонала.

1. **Защита от накладок в расписании.**
   В ядре базы данных (на уровне SQL) настроены строгие проверки. Попытка сохранить приём на уже занятое врачом время будет жёстко заблокирована самой СУБД, что исключает появление дублей в расписании.
2. **Динамический биллинг.**
   Стоимость приёма не вводится вручную. Она вычисляется серверной частью базы данных (через систему триггеров) как сумма всех оказанных услуг. Если врач удалит или изменит услугу, итоговая сумма чека мгновенно пересчитается.
3. **Атомарность операций.**
   Процесс оформления приёма с полным списком манипуляций защищён транзакцией. Система либо сохранит приём со всеми услугами целиком, либо отменит операцию полностью, не оставляя «битых» записей.
4. **Визуальный стиль.**
   Интерфейс выполнен в спокойной медицинской гамме. Цветовая индикация статусов приёмов (ожидание, завершение, отмена) и понятные формы ввода делают работу администратора быстрой и комфортной.

## 💻 Технологический фундамент

- **Среда разработки:** Kotlin, Android Studio
- **Пользовательский интерфейс:** Jetpack Compose (декларативный UI)
- **Хранение данных:** Room Database (SQLite) с поддержкой внешних ключей (Foreign Keys)
- **Архитектурный паттерн:** MVVM (Model-View-ViewModel)
- **Управление потоками:** Kotlin Coroutines & Flow

## 🚀 Инструкция по развёртыванию

1. Склонируйте исходный код проекта на локальную машину:

   ```bash
   git clone https://github.com/SuNa-rus/SmileCare.git
   ```

2. Импортируйте проект в среду **Android Studio**.
3. Дождитесь окончания сборки Gradle.
4. Инсталлируйте приложение на подключённое устройство или эмулятор (требуется Android 7.0 и выше).

*При первом старте база данных инициализируется демонстрационным набором данных, включающим врачей, пациентов и историю приёмов.*
